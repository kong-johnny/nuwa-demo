# 神韵山海 · 女娲篇

儿童神话互动体验，包含剧情、造人小游戏、古籍排序、云启问答和海报生成。

## 本机运行

需要 Python 3.10+，使用标准库，无需 pip 安装。

1. 设置环境变量 `ZHIPU_API_KEY`，或运行 `python save-key.py`，通过隐藏输入保存在本机 `.local-key`。
2. 运行 `python server.py`。
3. 打开 http://127.0.0.1:8787/ 。

入口：`/` 为起始页，`/play` 为故事，`/?test=poster` 为独立海报测试。未设置密钥也可打开故事，但真实问答与生图会提示尚未配置。

本仓库不包含 API 密钥、会话数据库、日志或用户生成图片。`.env.example` 仅展示变量名；程序不会自动加载 `.env`。

## API 与试用限制

后端只调用 `glm-4-flash-250414` 和 `cogview-3-flash`，不自动切换收费模型。模型可用性及价格以服务商当前政策为准。

浏览器会话每天最多30次问答、3次生图请求；全站每天最多200次问答、20次生图请求，失败尝试也计数。同一会话的同一旅程成功生成后复用图片。生成图片保存在 `generated/`，额度与记录保存在 `trial.sqlite`，均不提交 Git。

这是轻量试用服务，包含提示词约束和服务商过滤，尚未接独立内容审核服务、用户登录或运营管理后台。故事进度留在浏览器；问题及描述由模型服务处理。不要输入个人隐私。

## Windows 脚本

`start-local.ps1` 在后台启动本机服务。公网试用需另行安装 Cloudflare 官方 `cloudflared`，并执行 `cloudflared tunnel --url http://127.0.0.1:8787 --protocol http2`。临时域名会变化，电脑必须保持开机联网。
