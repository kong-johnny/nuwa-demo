# 神韵山海 · 女娲篇（nuwa-demo）

一个面向 8—12 岁儿童的**中国神话互动叙事原型**。玩家跟随女娲走过 21 幕旅程：捏土造人、翻阅古籍、排布补天次序、写下自己心中的神话画面，最后留下一张旅程海报。

**同一套故事数据与页面控制器，同时驱动微信小程序原生版与网页版**——网页版通过一层轻量 DOM 适配器运行，无需任何构建工具。

## 在线体验

打开仓库主页 `index.html`，点击「开始游玩」即可进入。

## 本地运行

```bash
node serve.js
```

默认监听 `http://localhost:8080`：

- 电脑浏览器打开 `http://localhost:8080/` → 项目主页
- 手机与电脑连同一 Wi-Fi，用终端输出的局域网地址打开即可在手机上玩

## 目录结构

```
index.html            项目主页（落地页，点击进入游玩）
home.css              主页样式
serve.js              本地静态服务器
web/                  网页版
  index.html          入口
  runtime.js          WXML → DOM 适配器 + wx API 垫片
  template.js         由 index.wxml 编译出的模板树
  style.css           基础样式
  desktop.css         桌面端适配层（悬停 / 键盘 / 宽屏 / 弹窗）
  desktop.js          桌面端交互层（快捷键 / 拖拽 / 焦点保持）
miniprogram/          微信小程序原生版
  lib/story.js        故事数据与流程
  lib/engine.js       状态机：存档、选择、校验
  pages/index/        页面控制器与 WXML 模板
  assets/             示例素材
```

## 手机与电脑都能玩

| | 手机 / 平板 | 电脑浏览器 |
|---|---|---|
| 布局 | 全屏竖屏，适配刘海安全区 | 宽屏画布，字号与间距同步放大 |
| 选择 | 点按，按下即有反馈 | 鼠标悬停高亮 |
| 古籍翻阅 | 左右滑动 | 滚轮横滑 / 鼠标拖拽 / 方向键 |
| 弹窗提示 | 原生样式轻提示 | 非阻塞的轻提示与确认弹窗 |
| 键盘 | — | `←` `→` 翻页、`1`—`4` 选项、`Enter` 继续、`Esc` 关闭 |

网页版还做了无障碍处理：全量焦点环、`aria-label` 标注、尊重系统的「减少动态效果」设置，页面重绘后键盘焦点位置不丢失。

- **AI 助教未接入**：「云启」为演示对话，外接接口待配置。

## 技术说明

网页版不重写业务逻辑。`web/runtime.js` 做三件事：

1. 把 `wx:if` / `wx:for` / `{{}}` 模板语法编译成 DOM；
2. 用 `localStorage`、原生弹窗、下载链接实现 `wx.*` API 垫片；
3. 复用小程序端的 `Page({...})` 控制器与 `engine.js` 状态机。

因此 `miniprogram/` 下的故事数据、状态机、页面控制器在两端**完全一致**，改一处两端同时生效。
